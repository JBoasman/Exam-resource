# Removed tooling

The HTML readers, embedded file-opening code, document generators, and Windows verification scripts were removed to keep the exam copy simple. The Markdown study documents and all question source, tests, data, and supplied library JARs remain.

Use `../LOCATOR.md` to find a file path and `../LINUX-SETUP.md` for manual Linux extraction and execution instructions. No tools in this directory are needed to read the notes or run an individual question.
